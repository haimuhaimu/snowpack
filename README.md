# 雪前 · Snowpack

手机优先的滑雪装备清单、装备画板与穿搭整理工具。支持单板、双板和两种都滑。

**在线使用：https://haimuhaimu.github.io/snowpack/**

## 手机上使用

在手机浏览器打开在线地址。iPhone 可通过 Safari 的分享菜单选择「添加到主屏幕」；Android 可在浏览器菜单中添加到主屏幕（选项以浏览器为准）。首次打开和首次自动抠图需要联网；本项目支持可选的私有云同步，尚未实现离线启动。

- 新建一次出发，按实际带好的装备逐项勾选。
- 装包、出发检查和租借领取分开核对；可按装备类别或收纳包查看。
- 装备库提供108项可选装备，包含能量胶、Insta360配件与电量/存储/试录检查。
- 场景补齐可按拍摄、交通与租借、过夜、返程选择本次需要的项目。
- 上传装备照片后可本地抠图，放到自由画板调整大小、位置、角度，保存搭配。
- 下次可沿用清单并重新核对；误勾可撤销，画板有撤销/重做。

## 记录与照片

记录先保存在当前浏览器，连接专属同步码后自动同步清单、衣橱照片、画板和搭配。手机与电脑各连接一次：右上角「设备同步」→粘贴同一个专属同步码。已连接的设备可复制同步码。同步码就是私人空间的访问凭据，不要公开或提交到 GitHub。

- 修改后自动保存并上传；页面打开时约每30秒检查另一端更新，回到页面或联网时也会检查。可点「立即同步」。网页关闭时不会在后台运行。
- 首次连接先读云端，未使用的默认清单不会覆盖已有记录。两边已经有记录时会提示选择同步起点。
- 不同项目的修改自动合并；同一内容冲突暂停同步，选择前会在当前设备自动保留两份恢复备份（最多4份）。选择按钮明确按整份记录处理。
- 断网或云端失败时本机修改保留；重新联网后继续同步。退出连接保留本机记录。清理浏览器数据会移除本机副本和同步码，重新连接前请确认同步完成。
- 手动导出/导入仍保留。导入替换本机记录，已经连接时也会参与后续同步。不同旧网址不会自动连接到新同步空间。

照片在浏览器本机抠图，不上传到推理服务。开启同步后，保存的照片和抠图会上传到私人云空间。云端采用 HTTPS、专属码验证和私有对象存储，未实现端到端加密；Vercel负责托管。未变化的照片按内容哈希复用，勾选清单只上传元数据。移出衣橱后不再出现在其他设备，但旧照片文件暂保留在私有存储内，本版不执行云端照片清理。

GitHub Pages 提供静态应用和可选抠图模型；首次抠图资源约16.5 MiB。模型是通用前景分割，人物上身照可能保留整个人，单独平铺/挂起的装备照片更合适。

清单适用于雪场内滑行。未勾选不等于未拥有或需要购买。

## 开发与发布

- `docs/`：完整静态应用，无构建依赖；所有资源使用相对路径，支持项目子目录。
- `tests/`：Node内置测试。
- `assets/brand/`：卡通标识原稿和来源说明，原稿不作为网页资源加载。
- Node.js 22+：运行 `npm test`。
- Python 3：运行 `npm run dev`，打开本机8081端口。
- GitHub Pages使用 `main` 分支的 `/docs` 目录；推送后自动发布。

`server/` 是独立同步服务，部署到 Vercel；先运行 `npm run prepare:server` 更新共享校验模块。服务配置见 `server/README.md`。`docs/sync-config.mjs` 仅放公开的服务地址，服务端凭据通过环境变量设置。不要将个人备份、照片和同步码提交到仓库。

Hobby 套餐的免费额度及限制以 Vercel 为准；超额可能暂停同步，本机记录仍可使用。本项目不自动升级付费套餐。

第三方模型、字体与图标的版本、许可证及校验值见 [THIRD-PARTY.md](THIRD-PARTY.md) 和相应资源目录。
