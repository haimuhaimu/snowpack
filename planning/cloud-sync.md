# 雪前自动同步：设计与实施

用户已选择专属同步码，手机和电脑各连接一次。继续使用 GitHub Pages 地址；为本人的记录增加独立私有云端，清单、衣橱照片、画板和搭配同步。界面保留现有样式。

## 设计
- GitHub Pages 保留静态前端；Vercel Function + private Blob 提供个人同步服务。邮箱账号需要额外认证服务，本次不采用；公开 GitHub 仓库不存个人记录或同步码。
- 为本人的空间生成随机256位同步码，服务端仅保存其SHA-256，所有数据读写必须验证Authorization。同步码是空间的访问凭据，不放URL/日志/公开代码。云端传输走HTTPS；私有存储，不宣称端到端加密。
- 照片按内容哈希单独上传且去重，元数据使用ETag条件写防止覆盖。读取最新版本不走过期缓存。前端保留现有v1数据结构，照片恢复后完整校验。
- 本机修改先保存。同步基线和冲突备份使用IndexedDB，避免重复占用localStorage。同步失败不阻止本机使用。
- 三方合并独立记录/字段；数量与状态、原照片与抠图成组，画板整体原子处理。重叠冲突保留两份，让用户选择；不得默默采用最后写入。
- 第一次连接云端已有记录且本机也有修改时，展示保留本机/使用云端选择并自动保存被替换快照。新浏览器的默认空衣橱清单可直接下载云端。
- 自动同步在保存后短暂合并、窗口重新激活和网络恢复时触发；页面可见时定时检查，隐藏时停止轮询。退出连接保留本机记录。
- 当前照片字符预算/本机保存限制仍生效。未验证真机前只报告浏览器尺寸与交互测试。
